# NEW-LEAF

New Leaf: digital shopping and payments platform, developed by DataWeave.
A static site (HTML/CSS/JS) styled after the Fume reference, in New Leaf's own brand.

Open `index.html` in a browser, or serve the folder (`python3 -m http.server`).
Pages: home, shop, product, cart/checkout, payments (planned), account (demo), about, design system.

- Design system spec for Lovable / FlutterFlow: `DESIGN_SYSTEM.md` and `design-system.html`
- Tokens: `css/tokens.css` · Demo catalogue + contact: `js/site.js`
- Images are placeholders; products are demo data with no prices; payments are "coming soon".
